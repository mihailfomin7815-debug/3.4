## Описание проекта

«Астероиды» — двумерная аркадная игра, в которой игрок управляет кораблём, уклоняется от астероидов и уничтожает их ракетами. Цель лабораторной работы — спроектировать многофайловое приложение и реализовать тайловую анимацию и взаимодействие игровых объектов.

После запуска игры можно управлять кораблём и стрелять по направлению его носа. Астероиды движутся и вращаются, а ракеты исчезают по истечении времени полёта. Столкновения и подсчёт очков находятся в разработке.

## Функциональные возможности

- Заставка, неподвижный фон и движущийся полупрозрачный слой с астероидами. Щелчок по заставке начинает игру с тремя жизнями и нулевым счётом.
- Поворот корабля, ускорение с переключением изображения двигателя и постепенное торможение после его выключения.
- Появление астероидов в случайных точках со случайной линейной и угловой скоростью. Корабль, астероиды и ракеты переходят через границы поля, сохраняя движение.
- Выстрелы из носа корабля. Ракета исчезает до того, как успеет пролететь расстояние, равное меньшей стороне поля.
- Анимация взрыва и одно очко за попадание в астероид. При столкновении с астероидом корабль теряет жизнь и возрождается неподвижным в центре. Если к моменту столкновения у игрока уже ноль жизней, игра возвращается к заставке и сохраняет итоговый счёт на экране.

## Требования к системе

- Python 3.11.
- Windows, macOS или Linux с графической средой.
- Pygame 2.6.1 для окна, обработки ввода и отрисовки.
- Git для клонирования репозитория.

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/mihailfomin7815-debug/3.4.git
cd 3.4
```

Если проект уже находится на компьютере, откройте терминал в его папке.

### 2. Создание и активация виртуального окружения

**Windows (PowerShell)**

```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
```

**macOS и Linux**

```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Установка зависимостей

```bash
python -m pip install -r requirements.txt
```

### 4. Запуск программы

```bash
python -m main
```

### 5. Управление

| Действие | Управление |
| --- | --- |
| Начать игру | Щелчок по заставке |
| Повернуть корабль | Стрелки влево и вправо |
| Включить двигатель | Удержание стрелки вверх |
| Выстрелить | Пробел |

## Структура проекта

```text
.
├── .gitignore
├── README.md
├── requirements.txt
├── assets/
│   ├── background.png
│   ├── asteroid.png
│   └── ship.png
├── src/
│   ├── app.py
│   ├── model.py
│   └── renderer.py
├── main.py
└── tests/
    └── .gitkeep
```

- `main.py` — точка входа.
- `assets/` — космический фон и спрайты астероида и корабля.
- `src/app.py` — окно, обработчики ввода и игровой цикл.
- `src/model.py` — параметры игры, игровые объекты, расчёт движения и столкновений, жизни и счёт.
- `src/renderer.py` — отрисовка заставки, фона, игровых объектов и счётчиков, а также анимация взрывов.
- `tests/` — автоматические тесты. Пока каталог содержит только `.gitkeep`, чтобы его можно было сохранить в Git.

Модель хранит состояние игры и рассчитывает движение независимо от окна. Отрисовка читает состояние модели, а приложение передаёт ей команды игрока и запускает обновление кадра. Такое разделение позволяет проверять движение и столкновения без графического интерфейса.

Изображения созданы встроенным инструментом ImageGen для этого проекта. Фон неподвижен, поверх него влево движется полупрозрачный слой текстурированных астероидов.

## Пример использования

Запустите `python -m main`. В окне будут видны заставка, три жизни и нулевой счёт. Щелчок левой кнопкой мыши по заставке скроет её. Щелчок за пределами заставки оставит её на экране.

## Тестирование

После реализации модели тесты на `unittest` проверят переход через границы поля, движение корабля, время жизни ракет, столкновения, начисление очков и потерю жизней. Запуск тестов из корня проекта:

```bash
python -m unittest discover -s tests
```
